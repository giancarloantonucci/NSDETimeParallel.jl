Glossary and quick reference

TermMeaning in a bulk Parareal run
ChunkOne of N time intervals
StartA stored initial value for a chunk; there are N
Boundary valuesThe starts plus the terminal fine output; there are N+1
Fine batchA round of fine propagation from the current starts
SweepA coarse correction between fine batches
SeamA fine endpoint minus the neighbouring stored start, up to sign
Exact completionMatching the chunked fine reference after at most N batches
Referencereference(problem, parareal), not the exact ODE solution
WeightPer-unit-time discount base; diagnostics store the value used by each batch
ζMeasured coarse/fine cost ratio for one chunk
WindowA MoWi subproblem, possibly overlapping its predecessor
ClippedA genuinely shortened endpoint window, excluded from default MoWi statistics

For finite bulk returns, fine_batches=sweeps+1. Partial failures need actual recorded counts. A pipeline has local iterations and no global batch count.

Reproducible and meaningful measurements

Record package versions and source revisions, Julia version, platform, backend, thread/rank counts, problem parameters, criteria, and floating-point types. Retain status, residuals, weights, fine/coarse call counts, and accuracy diagnostics. Save seeds whenever initial conditions, forcing, or analysis use randomness. Deterministic tests can establish agreement for a specified configuration; they do not promise bitwise agreement across platforms, BLAS libraries, compiler versions, random right-hand sides, or different operation orders.

Store portable tables alongside Julia-specific serialized records. Only deserialize trusted Julia files. Include a reference-completion check and a step-refinement check appropriate to the accuracy claim. Benchmark warmed-up runs and state whether setup, collection, and communication are included. Cache reuse reduces setup cost but does not make it zero. The tiny tutorial problems teach the API; they are not demonstrations of parallel speed-up.
